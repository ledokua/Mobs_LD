# Cinder Runt

Emberroot's melee minion has a 1.0 × 1.6 block hitbox and covers 0.58 blocks per walk cycle. Its split crown,
furnace ribs, and ember-tipped claws use the same palette as Kiln Sprout. The rest pose faces north.
